📌 Project Highlights
Using Python and Excel, I worked on:
 🔹 Data Cleaning & Preprocessing
 🔹 Exploratory Data Analysis (EDA)
 🔹 Visualization using Matplotlib & Seaborn
 🔹 Interactive Excel Dashboard creation
 🔹 Insight generation for decision-making

🧠 Key Insights
Patient ratio (Male : Female) = 52 : 48
Most common medical conditions: Asthma, Cancer, Obesity
Average stay duration: 12-15 days
Peak admissions: June to August
Critical cases had the highest billing amount
