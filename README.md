# 📊 Data Analysis Projects

A collection of end-to-end data analysis projects showcasing skills in Python, SQL, Excel, and Power BI — covering data cleaning, exploratory data analysis, and interactive dashboard design.

---

## 📁 Projects

### 1. [Superstore Sales Analysis](./Superstore_sales_analysis)
**Tech Stack:** Python, MySQL (SQLAlchemy), Excel, Power BI

An end-to-end sales analytics project on retail transaction data — from data cleaning in Python, to advanced SQL analysis (including window functions like `DENSE_RANK()` and `LAG()`), to an interactive Power BI dashboard with year/state filters.

**Highlights:**
- Cleaned and analyzed ~9,800 sales records
- Wrote SQL queries ranging from basic aggregations to window functions and nested subqueries for customer ranking and month-over-month growth analysis
- Built an interactive Power BI dashboard with KPI cards, regional and category breakdowns, and monthly trend visualizations

[View Project →](./Superstore_sales_analysis)

### 2. [Hospital Patient Data Analysis](./Healthcare_Data_Analysis)
**Tech Stack:** Python, Excel

A healthcare analytics project analyzing hospital patient records to uncover trends in admissions, billing, and demographics, presented through an interactive Excel dashboard.

**Highlights:**
- Cleaned and analyzed 55,000+ patient records
- Identified key patterns in admission type, patient age groups, and medical conditions
- Built an interactive Excel dashboard with year/month slicers and KPI tracking
